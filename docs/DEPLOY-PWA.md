# Superseded by DEPLOY.md

The web app used to live in a top-level `pwa/` folder. It is now
`sale/app/`, inside the one folder that maps to `public_html/`.

For installing it on an iPhone: open **https://sale.madeforu.co.in/app/**
in Safari (Chrome on iOS cannot do this), tap **Share**, then **Add to
Home Screen**. The sign-in screen says so itself, so partners do not need
talking through it.

For deploying it, see **`docs/DEPLOY.md`**.
